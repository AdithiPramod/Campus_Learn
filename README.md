# CampusLearn

A student learning portal built using HTML, CSS and JavaScript.

## Project structure

```text
CampusLearn_GitHub/
├── index.html
├── style.css
├── script.js
├── README.md
└── images/
    ├── coding.svg
    ├── study-space.svg
    ├── students.svg
    ├── team-study.svg
    └── campus.svg
```

## Run the website
Open `index.html` in a browser.

## Upload to GitHub
Upload all files and the `images` folder to your repository. The main page is `index.html`.

For GitHub Pages, enable Pages from the repository's Settings and select the branch containing these files.
